# 🌾 AgroVision — Smart Agriculture Assistant

AgroVision is an AI-powered smart agriculture platform designed to help farmers make better farming decisions using **Artificial Intelligence, Machine Learning, IoT sensor data, irrigation monitoring, and multilingual support**.

The system is designed especially for farmers who may not be comfortable with complex English-based applications. AgroVision provides a simple interface with **English and Kannada language support**.

---

## 🚀 Features

### 🌱 AI-Based Crop Disease Detection

Upload an image of a crop/plant leaf and AgroVision uses a Machine Learning model to identify possible crop diseases.

- 📷 Image-based disease detection
- 🤖 ML-powered prediction
- 📊 Prediction confidence
- 🌿 Disease information
- 💡 Recommended actions

---

### 🤖 AgroVision AI Chatbot

AgroVision includes an AI-powered agricultural chatbot that helps farmers with farming-related questions.

The chatbot can provide guidance about:

- 🌾 Crop selection
- 💧 Irrigation
- 🌱 Soil conditions
- 🌡️ Temperature
- 💦 Humidity
- 🦠 Crop diseases
- 🌿 Crop care
- 🧪 Fertilizer guidance
- 👨‍🌾 General farming practices

The chatbot uses **Google Gemini API** for AI-powered responses.

Should I irrigate now?

What can I grow in black soil?
